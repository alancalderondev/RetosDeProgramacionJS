# Reto #1 - Calculadora Digital

## Descripción
El reto consiste en crear una calculadora de base con la funcionalidad de sumar, restar, multiplicar y dividir dos números enteros.

## Lenguajes de programación

- HTML
- CSS
- JavaScript

## PRO TIP

- Utilizar *eval()* para realizar operaciones aritméticas en JavaScript.
